# Changelog

Older releases of macbook81-cs4208. The latest changes stay in the README. When a new version is tagged, the previous one moves here. Newest first.

## [v0.1.1](https://github.com/brontsor/macbook81-cs4208/releases/tag/v0.1.1)

The README no longer says this package installs the PipeWire and WirePlumber configs or the speaker node. Those belong to macbook81-audio-profile. install.sh still registers the DKMS package, installs the headphone jack watcher, and rebuilds the Limine UKI.

## [v0.1.0](https://github.com/brontsor/macbook81-cs4208/releases/tag/v0.1.0)

First release. Fork of omnidecker/macbook8.1-speaker-driver at e4134fb, itself a fork of thomas-shirley/macbook8.1-speaker-driver. The headphone unplug move is in this package.
